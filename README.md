# 🤖 ربات خبری فارسی تلگرام (رایگان و خودکار)

این ربات هر ~۱۰ دقیقه خبرهای جدید را در این موضوع‌ها (به ترتیب اهمیت) جمع می‌کند: 🇮🇷 ایران و سیاست، ⚔️ جنگ‌ها و اخبار نظامی دنیا، 💹 فارکس/دلار/طلا/نفت/بانک‌های مرکزی، ⚽️ فقط نقل‌وانتقالات بازیکنان و تیم‌های بزرگ — را از سایت‌های خبری می‌گیرد، به فارسی ترجمه می‌کند و در کانال تلگرام شما می‌گذارد. روی سرورهای رایگان GitHub اجرا می‌شود؛ کامپیوتر شما لازم نیست روشن باشد.

## مرحله ۱: ساخت ربات تلگرام
1. در تلگرام به **@BotFather** پیام بده و `/newbot` را بفرست.
2. یک اسم و یک یوزرنیم (که به `bot` ختم شود) بده.
3. BotFather یک **توکن** می‌دهد (مثل `123456:ABC...`). آن را جایی امن نگه دار و به کسی نده.

## مرحله ۲: ساخت کانال و ادمین کردن ربات
1. یک کانال بساز (Public با یوزرنیم، مثلاً `@mynewsfa`، ساده‌تر است).
2. کانال ← Administrators ← Add Admin ← ربات را پیدا کن و اجازهٔ **Post Messages** بده.
3. **شناسهٔ کانال:** اگر کانال عمومی است همان `@mynewsfa` است. اگر خصوصی است: یک پیام در کانال بفرست، آن را به ربات **@userinfobot** یا **@RawDataBot** فوروارد کن؛ عددی مثل `-100123...` می‌دهد.

## مرحله ۳: ساخت مخزن در GitHub
1. در github.com ثبت‌نام/ورود کن. بالا سمت راست ➕ ← **New repository**.
2. یک اسم بده، حالت **Public** را انتخاب کن (برای رایگان بودن نامحدود) ← **Create repository**.
3. در صفحهٔ مخزن روی **Add file ← Upload files** بزن و این فایل‌ها را بکش و رها کن: `bot.py`، `feeds.yaml`، `requirements.txt`، `README.md` و پوشهٔ `state` (با فایل `seen.json`). سپس **Commit changes**.
   - اگر پوشهٔ state آپلود نشد: Add file ← Create new file، در جای اسم بنویس `state/seen.json` و محتوا: `{"seen": []}`.
4. فایل workflow (پوشه‌های نقطه‌دار معمولاً با آپلود وب درست نمی‌روند): **Add file ← Create new file**، در کادر اسم دقیقاً بنویس:
   `.github/workflows/news.yml`
   (با تایپ `/` خودش پوشه می‌سازد). محتوای فایل `news.yml` را کپی و paste کن ← **Commit changes**.

## مرحله ۴: گذاشتن رمزها (Secrets)
مخزن ← **Settings** ← منوی چپ **Secrets and variables ← Actions** ← **New repository secret**:
- نام: `TELEGRAM_BOT_TOKEN` — مقدار: توکن BotFather
- نام: `TELEGRAM_CHANNEL_ID` — مقدار: `@mynewsfa` یا `-100...`

## مرحله ۵: روشن کردن و اجرای اول
1. تب **Actions** ← اگر پیامی برای فعال‌سازی دیدی، دکمهٔ سبز را بزن.
2. از چپ **new## تنظیمات (همه در فایل `feeds.yaml`)
- **اولویت:** اگر خبرها زیاد باشند، اول ایران، بعد جنگ، بعد فارکس، بعد نقل‌وانتقالات گذاشته می‌شود (`priority`).
- **کلمات فیلتر:** هر دسته `include` (کلماتی که باید باشد) و `exclude` (کلماتی که نباید باشد) دارد. می‌توانی کلمه اضافه/حذف کنی.
- **فوتبال:** خبر فقط وقتی گذاشته می‌شود که هم کلمهٔ نقل‌وانتقال (transfer, signs, loan, deal...) داشته باشد و هم اسم یک باشگاه یا ستارهٔ بزرگ از لیست `require_also`. برای اضافه کردن تیم/بازیکن، اسم انگلیسی‌اش را به همین لیست اضافه کن.
- **منابع:** بخش `feeds`. با `filter: true` فقط خبرهای مرتبط از آن منبع رد می‌شوند.

- برای ویرایش در سایت GitHub: روی فایل کلیک کن ← آیکن مداد ✏️ ← تغییر بده ← Commit changes.
- تست بدون ارسال (فقط برای کسی که پایتون دارد): `DRY_RUN=1 python bot.py`

## نکته‌ها
- GitHub زمان‌بندی را گاهی ۵ تا ۳۰ دقیقه دیرتر اجرا می‌کند؛ پس «لحظه‌ای» نیست.
- ترجمه ماشینی رایگان است و ممکن است گاهی دقیق نباشد. اگر ترجمه شکست بخورد، متن انگلیسی گذاشته می‌شود.
- اگر خبر زیادی همزمان بیاید، بقیه رد می‌شوند تا کانال شلوغ نشود.
- اگر خطا داد: تب Actions ← روی اجرای قرمز کلیک کن و خطا را ببین (معمولاً توکن/شناسه اشتباه یا ربات ادمین نیست). همچنین Settings ← Actions ← General ← Workflow permissions را روی **Read and write** بگذار.
